# The 8th Shop storefront redesign

## Goal
Reshape the customer storefront into a mobile-first editorial showroom: an immersive opening, three edge-to-edge package stories, compact visual categories, and a clean product grid that leads directly into the footer.

## Homepage
- Keep the existing introductory animation, but give its main line a distinct, highly readable display-serif treatment and refine its mobile scale.
- Keep the full-screen opening image and remove the current New Arrivals block so the visual story continues without a white interruption.
- Replace the current middle homepage sections with three full-bleed, gapless package panels:
  1. **For Us** — use the matching-couples product and imagery.
  2. **Thoughtful Package For Him** — use the strongest men-suitable product currently available.
  3. **For Her** — use the signature curated gift set.
- Each panel will use live product title, description, price, and stock data; the full visual links to its product page. Overlay controls will add the item to the bag or add it and go straight to checkout.
- Add a compact **Categories** strip with image thumbnails and clear titles, covering For Her, For Him, For Us, watches, necklaces, bracelets, and sets. Category destinations will resolve to the shop with an appropriate filter when possible.
- Follow it with one clean all-products grid, then the existing site footer. Remove New Arrivals, Shop by Chapter, Best Sellers, brand-story, homepage reviews, and the extra WhatsApp band from the homepage flow.

## Product browsing and navigation
- Update desktop and mobile navigation to **Shop**, **Categories**, and **Help Center**; remove Collections, Gifts, and About.
- Add a dedicated Categories page using the same compact visual language and product-backed destinations.
- Update the shop page to accept category/filter links from the homepage and Categories page without changing catalogue or pricing logic.
- Add short product descriptions to product cards while preserving image transitions, wishlist, and add-to-bag behavior.
- Update footer links to match the revised customer navigation.

## Product detail page
- Keep the existing multi-image gallery, full product information, specifications, stock, quantity selector, wishlist, and recommendations.
- Add an explicit **Buy Now** action that preserves the selected quantity and opens checkout.
- Move the current customer testimonials into a dedicated reviews section on product pages only.
- Keep KSh formatting, M-Pesa checkout, inventory limits, cart persistence, and existing checkout behavior unchanged.

## Help Center
- Add a dedicated Help Center page with concise delivery, payments, exchanges, and ordering guidance.
- Include an interactive contact form with validation and a clear WhatsApp support action. The form will open a prepared support message through the existing WhatsApp channel, avoiding invented email delivery behavior.

## Visual and mobile behavior
- Use the existing ivory, ink, clay, and editorial type system, adding only a dedicated intro display face.
- Build package panels as stable full-viewport visual stages with readable image scrims and bottom-aligned controls; no gaps between panels.
- On small screens, keep controls fully visible, stack actions where required, constrain text length, and retain touch-friendly button sizing.
- Respect reduced-motion preferences and retain the existing subtle image and entrance movement.

## Verification
- Verify the homepage on desktop and mobile for gapless package transitions, readable overlays, card sizing, and navigation.
- Exercise Add to Cart and Buy Now from a package panel and from a product page through to the checkout screen.
- Verify category navigation/filtering, Help Center form behavior, and that customer reviews no longer appear on the homepage.
- Confirm every updated content page has complete, unique sharing metadata.

## Assumptions
- Existing catalogue products and uploaded imagery will be reused; no sample prices or new inventory will be fabricated.
- The three package stories will be mapped to the closest existing live products, so admin catalogue updates continue to flow into the storefront automatically.
